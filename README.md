# Portfólio — Roberto Jefferson

React + TypeScript + Vite + styled-components.

## Rodar localmente
```
npm install
npm run dev
```

## Publicar na Vercel
Suba a pasta para um repositório no GitHub e importe na Vercel
(Framework: Vite, build `npm run build`, saída `dist`).

## Editar conteúdo
Projetos, skills e formação ficam em `src/dados.ts`.
Para adicionar o link de um projeto no ar, preencha `online`.
